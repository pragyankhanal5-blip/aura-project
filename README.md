# AURA Pro — Premium Wireless Headphones Landing Page

## Overview

AURA Pro is a modern premium product landing page designed for showcasing high-end wireless headphones. The project focuses on immersive user experience, smooth animations, interactive product exploration, and luxury-inspired visual design.

## Features

* Modern dark-themed user interface
* Animated loading screen
* Interactive hero section
* 3D product viewer
* Product rotation and exploration
* Dynamic feature showcase
* Responsive mobile-first design
* Authentication modal system
* Pre-order modal functionality
* Advanced CSS animations
* Canvas-based visual effects
* Premium product presentation

## Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript
* Canvas API
* Responsive Web Design
* Modern UI/UX Principles
